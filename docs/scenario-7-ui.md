# Сценарий 7 — Администратор

> Исторический отчёт переноса HTML. Текущие маршруты и подключение API описаны в [frontend-api-status.md](frontend-api-status.md). Упомянутые ниже .dc.html — внутренние имена эталонных экранов.


Источник: предоставленный командой `Сценарий 7 · Администратор.html`.
Семь экранов перенесены с исходными текстами, CSS и размерами.

Начало: http://localhost:3000/AD_Login.dc.html.

| Экран | URL |
|---|---|
| Вход | `/AD_Login.dc.html` |
| Все заявки | `/AD_All.dc.html` |
| В работе | `/AD_InWork.dc.html` |
| Закрытые | `/AD_Closed.dc.html` |
| Завершённые | `/AD_Done.dc.html` |
| Карточка выданного кредита | `/AD_DetailDone.dc.html` |
| Карточка автоотказа | `/AD_DetailDeclined.dc.html` |

Исходный отсутствующий `Main.dc.html` в ссылке выхода заменён собственным входом
администратора `/AD_Login.dc.html`. Новые экраны не добавлены.

Проверено: семь PNG совпадают с исходными HTML попиксельно при viewport 1440×720,
1440×1000 и 1440×1100; пройдены 14 переходов кликами по видимым элементам:
вход, вкладки, обе карточки, возвраты, выход и повторный вход.

Повторная проверка:

1. `python frontend/scripts/import-prototype.py <html> --scenario 7 --references frontend/.qa/scenario7-reference`
2. Отдельный headless Chrome с портом 9223 и отдельным профилем.
3. `node frontend/scripts/check-scenario.mjs 7`.

Артефакты находятся в игнорируемой `frontend/.qa/scenario7-qa`.

Это UI-прототип, без API-интеграции. Таблицы, скоринг, договоры и журнал пока
содержат данные HTML. Администратор представлен в режиме просмотра, без
принятия кредитных решений. Backend уже предоставляет очередь всех заявок
и карточку для роли admin; их ещё нужно подключить во frontend.
