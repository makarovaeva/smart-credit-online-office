## Автоматические состояния

По уточнению пользователя служебные ссылки «Обновить статус» из макета убраны.
В текущем UI-демо через 8 секунд автоматически сменяются:

- Главная после подачи → запрос документов.
- Чат проверки → чат с дозапросом и дополнением документов.
- Главная на рассмотрении → отказ андеррайтера.

Это демонстрация готовых состояний HTML, без банковских решений на frontend.
При подключении backend таймер нужно заменить получением фактического состояния
заявки из API. Ввод и загрузки не сохраняются; SMS, модель и скачивания не подключены.
Новые экраны для кнопок без действий в исходнике не добавлены.

## Проверка

Визуальный эталон — исходный HTML с удалёнными только служебными ссылками
«Обновить статус». Сравнение выполнено в одном Chrome при исходных размерах
1440×720, 1440×1000, 1440×1200 и 1440×1400. Проверяются все 13 экранов,
цепочка из 16 переходов и три автоматических перехода без нажатий.

Повторение:

1. Импортировать HTML: `python frontend/scripts/import-prototype.py <html> --scenario 2 --references frontend/.qa/scenario2-reference`.
2. Запустить отдельный headless Chrome с портом отладки 9223 и отдельным профилем.
3. Выполнить `node frontend/scripts/check-scenario.mjs 2`.

Скриншоты и отчёты находятся в игнорируемой `frontend/.qa/scenario2-qa`.
