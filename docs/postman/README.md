# Postman-коллекция

- `smart-credit.postman_collection.json` — коллекция (Postman Collection v2.1).
- `smart-credit.local.postman_environment.json` — окружение для локального запуска: `baseUrl`, демо-логины сотрудников и пароль.

Коллекция генерируется скриптом `backend/scripts/export_postman.py`. Правьте скрипт, а не JSON, и перегенерируйте:

```bash
cd backend && uv run python -m scripts.export_postman
```

Тест `tests/test_postman.py` падает, если JSON отстал от скрипта или в коллекции есть запрос, которого нет в OpenAPI.

## Сценарии

Запускайте коллекцию **целиком и по порядку**: токены и id передаются между запросами через переменные коллекции. Данные — демо-учётки из `scripts/seed.py`, они загружаются при старте backend.

| Папка | Что проверяет |
|---|---|
| 0. Готовность | Сервис и БД доступны |
| 1. Happy path | Клиент `+7 999 000-00-01`: вход по телефону → черновик → согласия и предварительный расчёт → подача (конвейер, зелёная зона) → андеррайтер одобряет → оффер → договор и график → подписание и выдача → «Кредиты» |
| 2. Контр-предложение | Клиент `+7 999 000-00-02`, 5 млн: пограничный риск, андеррайтер выбирает вариант «дольше срок» из AI Credit Memo |
| 3. Автоотказ | Клиент `+7 999 000-00-03`: стоп-фактор (банкротство), заявка закрыта с причиной |
| 4. Эскалация | Клиент `+7 999 000-00-04`: бизнесу 7 месяцев, жёлтая зона, заключение аналитика возвращает заявку андеррайтеру |
| 5. Документы и дозапрос | Клиент `+7 999 000-00-06`: счёт в другом банке, подача → дозапрос ИИ на выписку → загрузка `files/vypiska.pdf` → ответ → конвейер продолжается → андеррайтер скачивает файл |
| 6. Ошибки | 401, 403, 404, 409, 422 |

Запрос загрузки файла ссылается на `files/vypiska.pdf` относительно папки коллекции: Newman находит его сам, в Postman выберите файл в теле запроса вручную.

Заявки назначаются сотрудникам автоматически по загрузке. Скрипт входа сотрудника сам определяет, кому из двух андеррайтеров (аналитиков) досталась заявка. Коллекцию можно запускать повторно на той же базе.

## Запуск

**Postman:** Import → оба файла → выбрать окружение «Smart Credit - local» → Run collection.

**Newman (CLI) в Docker**, при поднятом `docker compose up`:

```bash
docker run --rm -v "$PWD/docs/postman":/etc/newman postman/newman:6-alpine \
  run smart-credit.postman_collection.json -e smart-credit.local.postman_environment.json \
  --env-var baseUrl=http://host.docker.internal:8000/api/v1
```
