## Переходы

В деморежиме через 8 секунд автоматически сменяются:

- Чат проверки документов → чат на рассмотрении.
- Главная после подачи → рассмотрение на главной.
- Рассмотрение на главной → предложение банка.

«Отклонить оффер» открывает состояние закрытой заявки без выдачи средств.
Повторная заявка, документы, кредиты и профиль доступны по исходным ссылкам.
Вариант «Принять оффер» в исходном HTML содержит `href="#"`; другая ветка
для него не добавлена. Кнопки без обработчиков остаются как в исходнике.

Таймер — демонстрация состояний, не кредитное решение и не банковская операция.
При интеграции он заменяется фактическим состоянием из API.
SMS, модель, реальные документы и сохранение формы пока не подключены.
