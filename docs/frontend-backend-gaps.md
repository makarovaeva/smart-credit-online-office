# Клиентский HTML и текущий backend

> Историческая сверка макета. Frontend теперь подключён к готовым методам API;
> актуальные маршруты, проверки и ограничения — в [frontend-api-status.md](frontend-api-status.md).

UI перенесён буквально по указанию пользователя. Этот список фиксирует вопросы для
следующего этапа интеграции; он не является разрешением менять макет.

| Макет | Backend / ограничение | Что согласовать |
|---|---|---|
| «Получить код», текст про SMS | Вход `POST /auth/login/phone` без SMS; сценарий кейса внутри продукта | Как подключить демо-вход с сохранением согласованного UI |
| Заявка оформляется через диалог с ИИ | В OpenAPI нет chat endpoint; есть отдельные команды заявок | Контракт чата и путь оформления без модели |
| Чат содержит готовые сообщения, предзаполненные суммы и решения | Это синтетические фиксированные состояния HTML | Связать отображение с данными заявки, не выдавать статические сообщения за ИИ |
| Документы, загрузки, ответы на дозапрос | Часть методов документов и дозапросов пока `501` | Реализовать backend перед реальной отправкой файлов |
| Клиентские состояния и кнопки зафиксированы отдельными HTML-страницами | API даёт `client_status`, `status_description`, `available_actions`, `version` | Подключить соответствующие состояния без дублирования банковской логики |
| Профиль компании — фиксированные значения | `/me` работает; привязка/редактирование компаний частично заглушены | Какие поля только показывать, какие можно редактировать |
| Оффер, подписание и выданный кредит показаны заранее | API имеет оффер, симуляцию подписи, договор и график | Подключить команды и обработку ошибок, сохраняя исходный UI |
| Макет в основном desktop 1440 px с фиксированными размерами | Пользователь просит абсолютное соответствие HTML | Адаптивные изменения пока не внесены; мобильная переработка требует отдельного согласования |

Готовые методы теперь подключены: вход, заявки, команды сотрудников, офферы,
подпись и договор используют backend. Указанные выше пробелы по чату, документам,
дозапросам и профилю всё ещё требуют доработок backend-команды.

Уточнение организаторов от 24.10.2026: допустим OpenAI-совместимый провайдер с моделью
с открытыми весами, заменяемыми base URL, ключом и названием модели. Проверяемая
версия не должна зависеть от платного доступа. Основной сценарий работает без ИИ.
Локальная модель и OCR могут работать вне Docker; источник и инструкции обязательны.
